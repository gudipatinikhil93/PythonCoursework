Funtions
-----------------------------------------
1. It is a reusable block of code used for specific tasks
2. It is used for program organization, it makes easy to understand and easy to debug
3. it takes the input and returns the output
4. It automates the task by calling it, instead of manually writing the code again
5. It makes the program smaller and less complicated

Advantages of Functions in Python
-----------------------------------------
Code Reusability — Write once and use multiple times.
Less Code Repetition — Avoid repeating the same logic.
Easy Debugging — Errors are easier to find and fix.
Better Readability — Makes code clean and organized.
Easy Maintenance — Changes can be made in one place.


Type of functions: Built-in Functions, User-defined Functions
